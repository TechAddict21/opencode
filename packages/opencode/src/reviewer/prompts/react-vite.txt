## What to Look For

**Bugs**
- Missing or incorrect hook dependency arrays
- Stale closures in useCallback/useMemo
- Memory leaks in useEffect cleanup
- Incorrect React key usage
- Props mutation or direct state mutation
- Race conditions in data fetching
- Missing error boundaries

**Structure**
- Component composition vs prop drilling
- Hook extraction and reusability
- Proper separation of UI and logic
- TypeScript prop types and generics

**Performance**
- Unnecessary re-renders
- Missing memoization for expensive computations
- Large bundle imports
- Inefficient list rendering
- Images without optimization

**Infinite-loop / runaway-render hazards (HIGH PRIORITY)**
- `useEffect` that `setState`s a value its own dependency array reads (or with a missing/over-broad dep array) → infinite re-render / refetch loop
- New object/array/function literals as deps or props each render, defeating memoization and re-triggering effects
- `setState` called unconditionally during render, or data fetching in render without a guard

**UX & interaction correctness**
- NO native `alert()` / `confirm()` / `window.prompt()` in user-facing flows — use a proper in-app modal / dialog / toast component instead
- Destructive or irreversible actions (delete, remove, overwrite, discard-on-edit) MUST go through a confirmation popup/dialog, not fire on a single unguarded click
- Forms: validation appropriate to each field (required, email/url/number ranges, min/max length, pattern); inline error messages; submit disabled/blocked while invalid — don't rely on the native browser bubble alone
- Dead controls: a button/link/handler that is empty (`onClick={() => {}}`), only `console.log`, or a `// TODO` — wire it up or flag it

**No AI-slop in the UI (same ban list as the design reviewer)**
- Banned, flag each with file:line: Sparkles/✨/`Wand2` "AI/magic" icons, `Bot`/robot avatars, emoji-as-icons (🚀🔥💡⚡🤖), "AI-powered"/"✨ Ask AI" badges, purple→pink/indigo cliché gradients, `bg-clip-text text-transparent` gradient text, glassmorphism-everywhere. Tell them to apply the `frontend-design` skill with a domain-appropriate icon/label instead.
